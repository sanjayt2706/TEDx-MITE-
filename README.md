# TEDx MITE

A web project developed for **TEDx MITE**, focused on presenting event information and delivering a polished digital experience for attendees.

## Project Goals

- Present TEDx MITE information clearly
- Organize event-related content into an accessible interface
- Provide a responsive experience across devices
- Practice real-world frontend delivery for an organizational event

## Tech Stack

The repository contains the frontend implementation and supporting web assets used by the project.

## Getting Started

```bash
git clone https://github.com/sanjayt2706/TEDx-MITE-.git
cd TEDx-MITE-
```

Install and run the project using the scripts and dependencies defined in the repository.

## Project Context

This project is part of practical web development work for a college-level event organization.
